# Review Checklist

- Confirm the change matches the task scope and allowed files.
- Check for behavioral regressions before style or refactor comments.
- Confirm validation commands are relevant and were actually run.
- Confirm error handling, edge cases, and rollback impact were considered.
- Confirm docs were updated when workflow, behavior, commands, or paths changed.
- Confirm generated artifacts, scratch notes, and unrelated files were not pulled into scope.
- Confirm high-risk operations still require explicit approval where repo rules demand it.
