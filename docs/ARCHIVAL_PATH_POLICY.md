# Archival Path Policy

## Purpose

Keep archival artifacts operationally useful after repository folder renames while preserving the original technical findings and timelines.

## Policy

1. Path strings in archival docs/logs/data are normalized to the current repository folder naming.
2. Historical conclusions, timestamps, and evidence summaries are preserved.
3. Each archival artifact must include an archival note that links to this policy.
4. If original raw evidence is needed with unnormalized paths, keep it outside the working docs set and reference it explicitly.
