# Remediation Playbook

Use concrete fix hints in check output. Preferred phrasing:

- "Create missing file at `<path>` and rerun gate."
- "Add workflow `<name>` under `.github/workflows/`."
- "Update changelog entry for version `<x.y.z>`."
- "Add required package script `<script>` to `package.json`."
- "Add packaging script `<path>` or adjust gate policy if intentionally unsupported."
